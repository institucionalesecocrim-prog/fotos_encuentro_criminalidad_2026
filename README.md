# Álbum de fotos – Encuentro Nacional de Agencias Públicas para la Investigación y Persecución de la Criminalidad Económica

Rosario, 5 y 6 de noviembre de 2026. Galería web con descarga individual y en ZIP.

Para agregar fotos: subirlas a la raíz del repositorio y sumar el nombre exacto (respetando mayúsculas, `.JPG`) a la lista `PHOTOS` dentro de `index.html`.
